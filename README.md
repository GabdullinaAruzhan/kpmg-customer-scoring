# Скоринг новых клиентов для Sprocket Central Pty Ltd

Учебный аналитический кейс (KPMG Data Analytics): по данным о существующих клиентах определить, каких из 1000 потенциальных новых клиентов стоит привлекать в первую очередь.

**Инструменты:** Excel (сводные таблицы, формулы), Power BI (дашборд из 4 страниц), критерий хи-квадрат, PowerPoint.

## Задача

Клиент хочет понимать не только, кто уже покупает больше всех, но и на кого из новых клиентов делать ставку. Нужно:

- найти самых лояльных клиентов в текущей базе;
- выяснить, чем они отличаются от остальных;
- присвоить каждому из 1000 новых клиентов балл и составить приоритетный список.

## Данные

Четыре таблицы: `Transactions`, `CustomerDemographic`, `CustomerAddress`, `NewCustomerList` (связь по `customer_id`). В сырых транзакциях 3 494 клиента; после очистки в анализе осталось 3 482. Оценивались 1000 новых клиентов.

> Данные учебные (вымышленный клиент, материалы KPMG Virtual Internship), поэтому в репозиторий не включены.

## Ход работы

1. **Проверка и очистка данных.** Подробности в [отчёте об очистке](docs/data_cleaning_report.docx):
   - удалены транзакции с `product_id = 0` (у них одновременно были пусты бренд, линия, класс, себестоимость и дата) и пустой столбец;
   - пропуски в `online_order` заменены на «Не указано», чтобы не приравнивать их к `False`;
   - значения пола и штатов приведены к единому виду;
   - найдена группа системно неполных анкет (неизвестный пол, пустые дата рождения и стаж), они исключены из анализа;
   - удалены записи с `deceased_indicator = «У»` и технический столбец `default`.
2. **Признаки.** Возраст и возрастные группы, прибыль по транзакции (`list_price − standard_cost`), геопризнак Remoteness Area (RA_INDEX, ABS), подтянутый по почтовому индексу.
3. **RFM-анализ.** По каждому клиенту посчитаны сумма покупок (Monetary), число транзакций (Frequency) и давность последней покупки (Recency). Каждый показатель переведён в процентный ранг (`PERCENTRANK.EXC`), итоговый балл: `RFM = 0.5 × M + 0.3 × F + 0.2 × R`. К самым лояльным отнесён топ-сегмент: 534 клиента с RFM не ниже 75,1 (около 15% базы).
4. **Сравнение с базой (lift).** Для каждого признака сравнивалась доля в топ-сегменте и доля по всей базе: `Lift = доля у лояльных / доля по базе`. Признаки без реальной разницы в модель не включались.
5. **Проверка значимости.** Критерий хи-квадрат, чтобы отличить закономерность от совпадения.
6. **Скоринг новых клиентов.** Каждому из 1000 новых клиентов присвоен балл по прозрачной формуле, затем клиенты ранжированы.

## Что выяснилось

Топ-сегмент: 534 клиента из 3 482. Для каждого признака сравнивалась доля в топ-сегменте и доля по всей базе (`Lift = доля у лояльных / доля по базе`), значимость проверялась критерием хи-квадрат.

| Признак | Доля у лояльных | Доля по базе | Lift | Вывод |
|---|---|---|---|---|
| Регион, RA_INDEX = 3 (Outer Regional) | 6.2% (33 клиента) | 4.3% | 1.44 | Единственный статистически значимый сигнал (p ≈ 0.025) |
| Регион, RA_INDEX = 2 (Inner Regional) | 14.0% | 13.0% | 1.08 | Слабый сдвиг, не значим (p ≈ 0.50) |
| Регион, RA_INDEX = 1 (Major Cities) | 79.4% | 82.3% | 0.97 | Практически как в базе |
| Индустрии Health, IT, Retail, Financial Services вместе | 46.6% | 46.9% | 0.99 | Различий нет (p ≈ 0.92) |
| Возраст, wealth segment, владение авто, стаж, оценка недвижимости | | | около 1 | Шум, от базы практически не отличаются |
| RA_INDEX = 4–5 (Remote) | 1 клиент в каждой группе | | | Слишком мало наблюдений |

Полная таблица: [`Lift_Table.xlsx`](results/Lift_Table.xlsx).

## Модель скоринга

```
score = (1, если индустрия in {Health, IT, Retail, Financial Services}, иначе 0)
      + (1, если RA_INDEX = 2; 2, если RA_INDEX = 3; иначе 0)
```

Максимум 3 балла. Распределение по 1000 новым клиентам:

| Балл | Клиентов | Доля |
|---|---|---|
| 0 | 432 | 43.2% |
| 1 | 464 | 46.4% |
| 2 | 83 | 8.3% |
| 3 | 21 | 2.1% |

Приоритетными считаются клиенты с баллом 2 и выше (104 человека).

**Важно:** повторная проверка показала, что баллы за индустрию и за RA = 2 не подтверждаются данными (lift около 1, различия не значимы), надёжный сигнал даёт только RA = 3. Модель оставлена в исходном виде как первая версия; следующий шаг — пересмотреть веса и оставить только подтверждённые признаки.

## Выводы и ограничения

- Единственное статистически значимое отличие лояльных клиентов географическое: они чаще живут в районах Outer Regional (RA = 3).
- Индустрия, возраст, уровень достатка, владение авто, стаж и оценка недвижимости не отличают лучших клиентов от остальных.
- Для Remote и Very Remote районов данных слишком мало, чтобы делать выводы.
- Главное ограничение: в топ-сегменте всего 33 клиента из RA = 3, поэтому вывод нужно проверить на новых данных.
- Версия модели с баллами за индустрию требует пересмотра (см. выше).
